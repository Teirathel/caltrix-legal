Caltrix is a Discord bot that integrates with Notion databases to publish schedules into Discord threads. Data We Store Caltrix may store the following per Discord server: Discord Server ID Configured channel and thread IDs Notion database IDs Optional Notion integration tokens (if configured by server admin) Message IDs for updating schedule posts Data Usage Stored data is used solely to: Publish and update schedule messages Maintain per-server configuration Data Sharing Caltrix does not sell, share, or distribute user data to third parties. Data Removal Server administrators may remove all stored data by: Removing the bot from the server Requesting deletion via contact Contact For data-related questions: [teirathel@gmail.com]
