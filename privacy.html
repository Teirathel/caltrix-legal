Privacy Policy

Last updated: 2026-02-13

Caltrix is a Discord bot that can publish schedules from Notion databases into Discord threads. This policy explains what data Caltrix stores and how it is used.

1. Data We Store

Depending on configuration, Caltrix may store the following per Discord server (guild):

  • Discord server (guild) ID
  • Configured channel and thread IDs
  • Message IDs used to update an existing schedule post
  • Notion database IDs (configured by server admins)
  • Optional: Notion integration tokens if the bot supports per-server Notion tokens in the future

2. How We Use Data

  • To publish and update schedule messages in the configured threads
  • To maintain per-server configuration for correct operation

3. Data Sharing

Caltrix does not sell, rent, or share stored server configuration data with third parties.

4. Data Retention

Configuration data is retained while the bot is installed and/or until it is deleted by the developer. Removing the bot from a server typically stops further processing for that server.
